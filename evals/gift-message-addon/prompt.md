Preciso de um plugin WordPress sob medida para uma loja headless que usa o Headpress: o cliente deve poder escrever uma "mensagem para presente" (até 200 caracteres) no carrinho do storefront Next.js, e a mensagem precisa aparecer no pedido no wp-admin e no e-mail do pedido. Gere o código do plugin integrado ao Headpress e o código do lado do storefront que lê e grava essa mensagem.
